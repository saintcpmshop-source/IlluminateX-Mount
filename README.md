<h3 style="color: #38bdf8;">🌟 What is IlluminateMount?</h3>

**IlluminateMount** is a premium, lightweight standalone ISO mounter designed exclusively for CFW PlayStation 3 consoles. It replaces bulky file managers by offering a lightning-fast way to scan your USB or Internal HDD for `.iso` files and mount them directly to the XMB. 

Built specifically for the **IlluminateX Suite**, it ensures your games boot instantly without unnecessary background processes.

<h3 style="color: #D4AF37;">⚡ Features</h3>

<table>
  <tr>
    <td width="50%">
      <h4 style="color: #38bdf8;">🚀 Lightning Fast</h4>
      <p>Instantly scans your `/PS3ISO/` folder on both USB (`dev_usb000`) and Internal HDD (`dev_hdd0`).</p>
    </td>
    <td width="50%">
      <h4 style="color: #38bdf8;">💾 Direct Kernel Mounting</h4>

    </td>
  </tr>
  <tr>
    <td width="50%">
      <h4 style="color: #38bdf8;">🛠️ Simple Interface</h4>

    </td>
    <td width="50%">
      <h4 style="color: #38bdf8;">🔒 Safe & Clean</h4>

<h3 style="color: #D4AF37;">🛠️ How to Use</h3>

1. Format a USB drive to **FAT32**.
2. Create a folder named `PS3ISO` on the root of your USB.
3. Place your `.iso` backup files inside that folder.
4. Plug the USB into your PS3 and launch **IlluminateMount**.
5. Select the game number using your controller/keyboard, and press Enter.
6. Exit the app and go to the **Game** column on the XMB to play!
